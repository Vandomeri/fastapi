# Учебный бекенд интернет-магазина (FastAPI + SQLite + JWT)

## Запуск

```bash
python -m venv venv
source venv/bin/activate        # Windows: venv\Scripts\activate
pip install -r requirements.txt
uvicorn main:app --reload
```

Swagger-документация: http://127.0.0.1:8000/docs

При первом запуске создаётся файл `shop.db`, администратор и 3 тестовых товара.

| Логин | Пароль   | Роль          |
|-------|----------|---------------|
| admin | admin123 | администратор |

## Маршруты

| Метод  | Путь              | Доступ        | Описание                      |
|--------|-------------------|---------------|-------------------------------|
| POST   | /auth/register    | все           | Регистрация                   |
| POST   | /auth/login       | все           | Вход, возвращает JWT          |
| GET    | /auth/me          | пользователь  | Текущий пользователь          |
| GET    | /products         | все           | Список товаров (`search`, `skip`, `limit`) |
| GET    | /products/{id}    | все           | Один товар                    |
| POST   | /products         | администратор | Создать товар                 |
| PUT    | /products/{id}    | администратор | Изменить товар                |
| DELETE | /products/{id}    | администратор | Удалить товар                 |
| POST   | /orders           | пользователь  | Оформить заказ                |
| GET    | /orders           | пользователь  | Мои заказы                    |
| GET    | /orders/{id}      | пользователь  | Один мой заказ                |

## Как проверить авторизацию

**Через Swagger:** откройте `/docs` → кнопка **Authorize** → введите логин и пароль.

**Через curl:**

```bash
# 1. Получить токен
curl -X POST http://127.0.0.1:8000/auth/login -d "username=admin&password=admin123"

# 2. Использовать токен
curl http://127.0.0.1:8000/auth/me -H "Authorization: Bearer <ВАШ_ТОКЕН>"

# 3. Оформить заказ
curl -X POST http://127.0.0.1:8000/orders \
  -H "Authorization: Bearer <ВАШ_ТОКЕН>" -H "Content-Type: application/json" \
  -d '{"items": [{"product_id": 1, "quantity": 2}]}'
```

Обратите внимание: `/auth/login` принимает **форму** (`username`, `password`), а не JSON —
так устроен стандарт OAuth2, на который опирается Swagger.

## Структура проекта

| Файл            | Что внутри                                         |
|-----------------|----------------------------------------------------|
| `main.py`       | Приложение и все маршруты                          |
| `database.py`   | Подключение к SQLite, сессии                       |
| `.py`     | Таблицы БД (SQLAlchemy)                            |
| `schemas.py`    | Схемы запросов/ответов (Pydantic)                  |
| `security.py`   | Хеширование паролей, создание и проверка JWT, роли |

## Упрощения, которые стоит знать

- Секретный ключ JWT лежит в коде — в реальном проекте он берётся из переменной окружения `SECRET_KEY`.
- Цены хранятся как `float` — для денег в реальных проектах используют `Decimal` или копейки в `int`.
- Нет миграций (Alembic): таблицы создаются через `create_all`. При изменении моделей удалите `shop.db`.
- Удаление товара не затрагивает старые заказы (цена в заказе фиксируется отдельно).
- Нет refresh-токенов: токен живёт 30 минут, потом нужно войти заново.
